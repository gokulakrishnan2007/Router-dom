# React Router DOM

## About the Project

This project is developed using React JS and React Router DOM.

It demonstrates how to navigate between multiple pages, create nested routes, and use dynamic routing in a React application.

## Features

- Home Page
- About Page
- Contact Page
- Services Page
- Navigation using Link
- Nested Routing using Outlet
- Dynamic Routing using useParams
- Welcome Message with Username
- Error Page for Invalid Routes

## Technologies Used

- React JS
- JavaScript
- React Router DOM
- HTML
- CSS
- Vite

## React Router Concepts

### 1. Link
Used to navigate between different pages without reloading the website.

### 2. Outlet
Used to display child components inside a parent route.

### 3. useParams
Used to get dynamic values from the URL, such as username.

### 4. Error Page
Displays a Page Not Found message when the user visits an invalid route.

## Installation

1. Clone the repository.
2. Open the project folder in VS Code.
3. Install the dependencies.

```bash
npm install
```

4. Start the development server.

```bash
npm run dev
```

## Project Purpose

The main purpose of this project is to learn React Router DOM and understand page navigation, nested routing, dynamic routing, and reusable components.
